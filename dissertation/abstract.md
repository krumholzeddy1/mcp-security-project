# Abstract

Anthropic's Model Context Protocol (MCP) has become the dominant standard for connecting large language model agents to external tools. Its design does not treat security as a first-class concern: each layer in the pipeline trusts the layer behind it, and nothing re-validates that trust once a session is established. This creates a distinct and growing class of attacks — tool poisoning — in which malicious servers embed instruction-like text in tool metadata fields, directing the model to perform actions the user did not authorise. The most difficult variant, the rug-pull attack, registers with a clean description and injects content only after the client has trusted the server, making it structurally invisible to every defence currently in use, because all existing defences inspect tool metadata once at registration and do not re-check it afterwards.

This dissertation adopts a positivist, quantitative design to investigate whether machine-learning-based anomaly detection of post-registration tool-call metadata can improve detection of tool-poisoning attacks compared with a schema-validation baseline. A controlled testbed was constructed using a real MCP server and client. A synthetic labelled corpus of 600 sessions — spanning benign, poisoned, and rug-pull classes — was generated with a documented noise model designed to produce overlapping feature distributions. Three classifiers (Logistic Regression, Random Forest, and Gradient Boosting) were trained on eleven metadata features and evaluated on a held-out test set, with a separate robustness check on a skewed corpus (90% benign / 5% each attack class) to test generalisation under class imbalance.

The decisive finding is rug-pull recall: 88.1–93.3% across all three ML models versus 0% for the baseline — a structural impossibility for any registration-time check, confirmed across both corpus distributions. Gradient Boosting achieves overall F1 of 0.945 versus the baseline's 0.488; under class imbalance, recall is preserved (0.967) while precision drops to 0.682, a trade-off reported in operational terms (5.0% false-alarm rate on benign sessions). Feature importance analysis confirms that 96.9% of the model's discriminative information derives from call-time features that the baseline cannot observe. The residual false-negative rate is attributed to stealthy rug-pulls that revert their mutation before the metadata snapshot, establishing a hard theoretical bound on point-in-time detection and motivating continuous session monitoring as future work.
